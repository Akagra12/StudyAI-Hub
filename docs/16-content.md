# 16 - Content Strategy, Structure & Editorial Guidelines

## Editorial Principles
Every piece of content on StudyAI Hub is crafted according to strict guidelines:
1. **Academic Honesty:** No fabricated claims, unsupported benchmark stats, or fake star ratings.
2. **Student First:** Explicit breakdowns of pricing tiers, GitHub Student Developer Pack claims, and free alternative tools.
3. **Curriculum Relevancy:** Code examples and prompt templates are grounded in real B.Tech CSE subjects (Operating Systems, DBMS, Dynamic Programming, PyTorch, Computer Networks).
